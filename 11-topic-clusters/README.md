# Topic clusters

A cluster is **one subject OS A.I owns**, modelled as a reusable record rather than an essay. A
writer picks a cluster; an [article brief](../12-content-engine/article-brief-template.md) turns it
into a specific piece.

## The seven fixed sections

**Every cluster file carries these, in this order, always.** Fixed headings are what make a cluster
queryable instead of prose.

1. **The customer pain** — in the customer's words where we have them, marked when we do not
2. **OS A.I's viewpoint** — the argument, including what the brand refuses to say
3. **The solution** — capabilities that apply, **linked** to `02`, never restated
4. **Supporting evidence** — every item tiered and sourced, **linked** to `05` or `06`
5. **Common objections** — with the turn, linked to `10`
6. **Keywords** — primary, secondary, and the questions people actually ask
7. **Article ideas** — titles with angle and intent, feeding `12`

## The normalisation rule — the one that matters

**A cluster never restates a fact. It links to the file that owns it.**

- A price lives in `02`. A cluster links to it.
- A statistic lives in [stats bank](../06-research-and-market/stats-bank.md). A cluster links to it.
- A capability lives in [platform capabilities](../02-offer-and-pricing/platform-capabilities.md). A cluster links to it.

When the price changes, one file changes. If clusters restated prices, nine files would silently go
stale — which is exactly how knowledge bases start disagreeing with themselves.

## What a cluster is not

**Not a fact source.** Clusters are the editorial layer. Everything factual in them is borrowed by
link from `01`–`07`. If a cluster seems to contain a new fact, that fact is in the wrong place.

## Keywords

Keyword sections are **`assumed`** across all nine clusters. No keyword research, search volume or
ranking data exists (gap G14). They are reasoned from the language in the ICP and problem files —
useful for structuring content, **not a validated SEO plan.** See [keyword map](../12-content-engine/keyword-map.md).

# Offer overview

OS A.I sells the same platform **two ways**, to two different buyers. Decision D1 in
[SCHEMA](../00-start-here/SCHEMA.md). Getting this distinction right matters more than any other
fact in the database, because the two lines have different prices, different buyers and different
objections.

| | **Subscription** | **Done-for-you** |
|---|---|---|
| What you buy | Access to the platform | The platform, built and installed for you |
| Price | $97 / $297 / $497 per month | Setup fee + monthly |
| Buyer | Wants to run it themselves | Wants it running without learning it |
| Objection | "Can I actually use this?" | "Why does setup cost that much?" |
| Source | **Live website — authoritative** | Business plan, 2026-03-22 |
| File | [subscription-plans](subscription-plans.md) | [done-for-you-services](done-for-you-services.md) |

**When copy says "pricing" with no qualifier, it means the subscription.** That is what the website
sells and what a cold reader will see.

## The subscription, at a glance

| Plan | Price | Partner payout |
|---|---|---|
| **Pro** | $97/month | 40% tier 1 |
| **Partner** | $297/month | 45% tier 1 + 5% tier 2 |
| **Platinum** | $497/month | 50% tier 1 + 30% tier 2 + 10% tier 3 |

A **7-day free trial** is offered. It **auto-converts to a paid subscription** unless cancelled —
this must be disclosed wherever the trial is promoted. See [ACL and consumer law](../07-compliance-and-guardrails/acl-and-consumer-law.md).

Note what the tier ladder actually escalates: **partner commission**, not obviously platform
capability. What functionally differs between Pro, Partner and Platinum beyond payout percentage is
**not documented anywhere** (gap G12). Copy must not invent feature differences between tiers.

## The done-for-you line

| Product | Setup | Monthly |
|---|---|---|
| Pro Chat Agent | $2,500 | $297 |
| Platinum Chat Agent | $6,800 | $497 |
| Pro Voice Agent | $5,500 | $297 |
| Platinum Voice Agent | $11,100 | $497 |

Plus two entry products from the business plan: **The Prompting Library (free)** and **The
Automation Library ($99)**. Neither appears on the live site — treat as `inferred` until confirmed.

## The value ladder

```
Free Blueprints / Prompting Library   →   free, listed in site nav
The Automation Library                →   $99          (not on site — unconfirmed)
Pro subscription                      →   $97/mo
Partner subscription                  →   $297/mo
Platinum subscription                 →   $497/mo
Done-for-you Chat Agent               →   $2,500–$6,800 setup + monthly
Done-for-you Voice Agent              →   $5,500–$11,100 setup + monthly
```

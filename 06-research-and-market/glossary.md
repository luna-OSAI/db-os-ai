# Glossary

Terms that appear in OS A.I content, and how to handle each with a non-technical reader.

## Use freely — the audience knows these

| Term | Meaning |
|---|---|
| **CRM** | The system holding every contact, conversation and deal |
| **Lead** | Someone who has raised their hand |
| **Pipeline** | The stages a deal moves through |
| **Funnel** | A sequence of pages moving a visitor toward one action |
| **Landing page** | A single-purpose page |
| **Follow-up** | Contacting someone after first contact |
| **Automation** | Something that happens without a person doing it |
| **Workflow** | A defined sequence of automated steps |
| **Booking / calendar link** | Self-service scheduling |
| **Tech stack** | The set of tools a business runs on |

## Explain on first use

| Term | Plain-English gloss |
|---|---|
| **Speed to lead** | How fast you respond after someone enquires |
| **Lead scoring** | Ranking leads by how likely they are to buy |
| **Nurture sequence** | Automated messages that stay in touch over time |
| **Trigger** | The event that starts an automation |
| **Attribution** | Knowing which marketing produced which customer |
| **Churn** | Customers who stop paying |
| **MRR** | Predictable monthly revenue |
| **Unified inbox** | Every channel's messages in one place |
| **Intent routing** | The AI working out what someone wants and sending them to the right place |
| **Knowledge base** *(agent sense)* | The material an AI agent is trained on |
| **Conversation AI** | An AI that handles a back-and-forth, rather than a scripted bot |

## Avoid entirely with an SMB reader

Fine with an agency founder; jargon to Ethan.

| Avoid | Say instead |
|---|---|
| Multi-object linking | Everything about a client stays connected |
| Node-based canvas | A visual builder |
| SDLC / staging environment | Tested before it goes live |
| Webhook | The systems talk to each other |
| MCP server / API call node | *Omit unless the reader asked* |
| Drip mode architecture | Messages are paced so they land properly |
| Schema markup | Helps search engines understand the page |

## Terms with a house rule

| Term | Rule |
|---|---|
| **GoHighLevel / HighLevel / GHL** | **Never client-facing.** Say "the platform" |
| **Chatbot** | Avoid for OS A.I's agents — it undersells them and carries bad associations. Say "AI chat agent" |
| **Bot** | Same |
| **Blueprint** | "Free Blueprints" is a live product name; the generic marketing use is banned |
| **AI agent** | Correct term for Oliver and Olivia. Never imply they are human |
| **10x** | Banned as a verb. The registered site claim "10× Faster" is permitted as-is |
